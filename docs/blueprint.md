# **App Name**: MindBloom

## Core Features:

- User Authentication: Secure login/registration page for users.
- Profile Creation: A popup prompts the user for their name, age, and profession (Student, Professional, House Parent).
- Dynamic Survey Generation: Based on the age and profession selected, generate a tailored survey of 12 questions, fetched from the application's memory.
- Response Analysis and Personalized Insights: The app analyzes user survey responses, and provides a personalized written summary of the user's probable mental state. The writing is performed by a generative AI tool.
- Dashboard Tab: Create dedicated dashboard tab to display personalized content based on survey responses.

## Style Guidelines:

- Primary color: Soft Lavender (#D1B0FF) for a calming and serene feel.
- Background color: Light Gray (#F0F0F0) to ensure readability and reduce eye strain.
- Accent color: Muted Blue (#A0D2EB) for interactive elements.
- Body and headline font: 'Inter', a sans-serif font, will provide a clean, neutral and modern look. It is suitable for both headlines and body text.
- Use minimalistic icons to represent different mental health aspects. Use different saturations of the primary color for inactive vs active icons.
- Simple, clean layout with ample white space to reduce clutter and promote focus.
- Subtle animations for feedback and loading states.
